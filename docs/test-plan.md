## 当前待验证事项

后续若用户授权真实编排测试，至少观察：

1. 主控收到已确认计划后的继续、开始执行时，是否按已记录的负责人和稳定ID分发，而非自己实施
2. 子对话完成、报错或需要改派时，是否把信息留在自身对话，不主动联系、唤醒或切换主控
3. 主控默认是否只做一次短状态检查后返回；用户要求保持运行监督时，是否增量审核并推进，30分钟无实质进展时检查且不打断正常任务，必须确认且无其他工作时停止
4. 用户改过子对话标题、模型或推理等级后，主控是否继续定位原稳定ID且不覆盖设置
5. 多目录或跨盘路径加入同一Codex项目后，任务包是否只授予已确认的最小权限范围
6. 用户未指定设置时是否按任务建议具体模型和推理等级，不回退到固定值；已有对话是否保持当前设置

这些项目在2026-09-24的文档整理中没有运行。当时读取了现存源文件、安装文件、评测JSON、历史日志与基线哈希，并额外运行一次只读结构校验；未运行模型评测、未创建真实侧边栏测试对话，也未访问历史E01、E02任务。2026-09-26仅复查文档和文件哈希，不运行Skill验证
