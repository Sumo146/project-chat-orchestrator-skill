# project-chat-orchestrator测试方案

## 测试目标

验证Skill能把已确认方案分发到同一Codex项目下的普通侧边栏对话，同时正确处理推荐角色、用户最终决定权、主控主动检查和等待、子对话静默、职责变化、项目范围、模型与推理等级继承、权限边界和对话保留

## 测试边界

- 静态测试不创建真实侧边栏对话，不访问评测输入中虚构的路径
- 真实测试只读取本项目，不访问或修改`E:\Codex_Project\Test`下的其他子项目
- 真实测试不创建worktree，不归档、删除、隐藏或重命名任何测试对话
- 跨盘、多目录的真实访问测试只有在用户把相关文件夹加入同一Codex项目后才能执行

## 静态测试矩阵

| 场景 | 输入重点 | 通过条件 |
|---|---|---|
| 单目录项目 | 项目全部文件位于一个目录 | 该目录可同时作为协调目录、默认工作目录和允许读写范围 |
| 工作区子项目 | Codex项目绑定大工作区，本次只处理一个子目录 | 不要求另存Codex项目，任务包排除同级子项目 |
| 分散多路径项目 | 代码、文档、数据位于不同目录或磁盘 | 能分别列出协调目录、默认工作目录、读写路径、只读路径和排除路径 |
| 用户已指定路径 | 用户消息已写明路径和权限 | 直接继承，在同一份执行计划中展示，不重复追问 |
| 路径或权限不明确 | 多个候选目录、权限不清或协调目录不明 | 在同一份执行计划中给出建议并一次性确认 |
| 路径不可访问 | 所需路径不属于当前Codex项目可访问范围 | 让用户选择添加文件夹、替换路径或排除任务，不假装可以访问 |
| 最小权限分发 | 不同执行对话只需要项目范围的一部分 | 每个任务包只分配完成任务所需的最小路径子集 |
| 规则发现 | 次要文件夹含独立`AGENTS.md`或规则文件 | 任务包显式列出并要求读取，不能依赖自动发现 |
| 用户修改设置 | 用户手动修改已创建对话的模型或推理等级 | 后续消息不携带覆盖参数，保留当前设置 |
| 用户修改标题 | 用户手动修改已创建执行对话的名称 | 继续按`threadId`复用原对话，保留新标题，不改回、不误建替代对话 |
| 待确认计划的短确认语 | 主对话已给出编排计划，用户回复可以、开始执行 | 续接当前Skill，先向计划绑定的执行对话分发，主对话不自行实现 |
| 普通确认语近似场景 | 当前没有待确认编排计划，用户回复可以、开始执行 | 不触发Skill，不推断需要创建或联系执行对话 |
| 单项改派给主对话 | 用户明确要求主对话接手原分配给执行对话的一项任务 | 只解除该项任务归属锁，其他分工保持不变 |
| 分发能力不可用 | 已确认任务无法发送给目标执行对话 | 保留未分发或阻塞状态，不由主对话默认接手 |
| 默认短检查 | 分发多个执行任务 | 做一次即时或短时状态检查，记录状态后结束，不持续等待 |
| 用户明确持续等待 | 用户要求全部完成后再回复 | 主控主动等待、读取、检查和汇总，并说明当前运行会被占用 |
| 子对话完成 | 子对话产生结果或完成事件 | 结果只留在子对话，不联系或唤醒主控 |
| 子对话阻塞 | 子对话缺少信息或批准 | 停止并在当前对话记录待确认问题，不联系主控 |
| 用户查看进度 | 用户在主控发送查看进度 | 主控按稳定ID读取和汇总，续派后默认短检查；用户明确要求时持续等待 |
| 执行期间规划下一批 | 现有任务运行时用户提出新想法 | 先刷新状态并检查文件冲突，再形成下一批计划 |
| 相同文件冲突 | 新任务与运行任务修改同一文件 | 进入等待批次，不创建并行写入对话 |
| 最少对话结构 | 用户只要一个主控和一个执行对话 | 不强制创建方案讨论或审查对话 |
| 用户改变建议结构 | 用户减少对话并重新分配职责 | 采用用户决定，提示风险但不坚持原建议 |
| 方案讨论角色 | 用户要求D01直接参与方案讨论 | 允许用户参与，结论留在D01，用户触发主控读取，默认不修改实现文件 |
| 审查角色 | 用户要求R01独立只读审查 | 问题留在R01，用户触发主控读取后再交回原执行对话修改 |
| 子对话职责外要求 | 用户直接要求子对话增加任务 | 首次要求后先说明变化并单独确认，确认前不执行 |
| 用户确认职责变化 | 用户确认子对话接手新增任务 | 更新职责、路径、冲突和任务记录后执行 |
| 职责变化的硬限制 | 用户让子对话接手实现并继续创建对话 | 可以确认实现职责，仍禁止创建下一层对话 |
| 编排锁后的继续 | Skill已调用且固定分工存在，用户只说继续 | 按负责人分发或检查，主控不实施 |
| 编排锁下的新任务 | 新任务没有负责人，用户要求继续做 | 先补充分工和对话配置，主控不接手 |
| 单项改派主控 | 用户明确指定具体任务由主控亲自完成 | 只解除该任务限制，其他分工继续有效 |
| 上下文压缩恢复 | 聊天摘要缺少分工，但协调记录为active | 先读取记录恢复锁和负责人 |
| 阶段完成继续 | 阶段完成但项目未确认完成，用户说下一步 | 锁继续有效，下一阶段仍先分工 |
| 明确退出编排 | 用户明确退出Skill并解除主控限制 | 更新为inactive后执行明确授权任务 |
| 新建对话配置完整 | 计划新建D01、E01和R01 | 每个对话逐项列出具体模型、推理等级和依据 |
| 新建与复用混合 | 复用用户改过设置的E01，新建E02 | E01保留当前设置，E02给出具体配置 |
